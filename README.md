# Questionnaire Scoring Explorer

A local, browser-based questionnaire scoring and exploration tool for the University of Padua psychology questionnaires.

## Included tools

- `questionnaire_tool.html`: shareable single-file browser application with Chinese, English, and Italian interfaces.
- `app.py`: Streamlit version of the analysis tool.
- `requirements.txt`: Python dependencies for the Streamlit version.

The browser tool supports scale-by-scale inspection, factor explanations, anomaly flags, scoring rules, participant and group summaries, and selectable bar/line visualizations.

## Use the shareable version

Open the deployed application:

https://questionnaire-scoring-explorer-jawjy8.vercel.app/

Upload the original Excel file in the browser. The data is processed locally in the browser and is not uploaded by the tool.
